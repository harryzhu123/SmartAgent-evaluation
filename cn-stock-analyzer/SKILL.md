# 中国A股新闻驱动选股分析

## 核心理念

这个 skill 的本质是：**把新闻事件翻译成投资信号**。核心逻辑链条是：

```
新闻/政策 → 情绪判断 → 受影响行业 → 产业链映射 → 具体标的 → 风险评估 → 输出建议
```

每一步都需要扎实的推理，而不是简单的关键词匹配。一条"国务院发布新能源汽车支持政策"的新闻，不仅仅影响比亚迪，还应该分析到锂电池、充电桩、稀土永磁、汽车电子等上下游环节。

## 工作流程

### 第一步：获取与解析新闻

有两种触发方式：

#### A. 用户提供新闻（被动模式）
- 上传包含多条新闻的文件（txt/csv）— 用 `scripts/parse_news.py` 解析
- 在对话中直接粘贴
- 提供 URL 让 Claude 用 web_fetch 抓取

#### B. 自动抓取新闻（主动模式）★
当用户说"帮我抓取XX相关新闻"、"自动搜集今天的XX消息"或类似意图时，执行自动抓取流程：

1. 运行 `scripts/fetch_news.py --mode workflow --topics "用户关注的主题"` 生成抓取计划
2. 按计划依次执行 web_search 和 web_fetch（按优先级：政策源 > 权威媒体 > 财经媒体）
3. 每次搜索后，从结果中提取：标题、来源、时间、核心内容、URL
4. 去重：同一事件的不同报道只保留最权威来源的版本
5. 同步抓取板块行情和资金流向数据
6. 将所有结果整理为结构化 JSON，进入后续分析流程

**自动抓取的新闻源优先级**（定义在 `scripts/fetch_news.py` 中）：
- P1 政策源：国务院网站、新华社、央行等 — 必搜
- P2 财经快讯：财联社电报、东方财富 — 必搜
- P3 深度报道：新浪财经、证券时报 — 视搜索额度搜

**快捷用法**：运行 `python scripts/fetch_news.py --mode prompt --topics "主题"` 可以生成一段直接发给 Claude 的提示词，一键触发完整抓取+分析流程。

**解析要求：**
1. 从新闻中提取：发布时间、来源（新华社/央视/国务院等权威来源要特别标注）、核心内容摘要
2. 对每条新闻进行**情绪判断**：强利好 / 利好 / 中性 / 利空 / 强利空
3. 识别新闻涉及的**行业关键词**和**政策信号**

**新闻来源权重**（权威性从高到低）：
- 第一梯队：新华社、央视新闻、国务院、中国人民银行、证监会 — 政策确定性最高
- 第二梯队：人民日报、经济日报、中国证券报 — 官方口径的延伸解读
- 第三梯队：财联社、券商研报、21世纪经济报道 — 市场消息和行业深度
- 第四梯队：微博财经大V、雪球讨论 — 情绪指标参考，事实需交叉验证

### 第二步：获取市场行情数据

使用多种方式获取实时/近期行情数据，按优先级尝试：

#### 方式一：Web Search（首选）
用 web_search 搜索以下关键词组合来获取行情：
- `"XXX板块 今日行情"` / `"XXX概念股 涨跌"`
- `"沪深两市 板块资金流向 今日"`
- `"XXX ETF 净值 今日"`
- `"东方财富 XXX板块"` 获取板块详细数据

#### 方式二：抓取财经页面（补充）
用 web_fetch 抓取以下数据源：
- 东方财富板块行情页面
- 新浪财经行业数据
- 同花顺概念板块页面

#### 方式三：用户提供数据
用户可能直接提供关注的板块或个股数据，直接使用即可。

**获取数据时的注意事项：**
- 交易时间（北京时间9:30-15:00）内的数据是实时的，其他时间获取的是收盘数据
- 要同时关注：板块涨跌幅、成交量变化、资金净流入流出、涨停/跌停家数
- 如果某个数据源无法访问，不要卡住，换一个来源继续

### 第三步：政策面分析（最高权重）

这是分析的核心维度，因为A股是典型的政策驱动市场。

**分析框架：**

1. **政策类型判断**
   - 财政政策：减税降费、专项债、财政补贴 → 直接利好受益行业
   - 货币政策：降准降息、LPR调整、流动性投放 → 利好大盘和利率敏感板块
   - 产业政策：行业规划、准入标准、技术标准 → 精准利好特定产业链
   - 监管政策：反垄断、数据安全、环保限产 → 可能利空被监管行业，利好合规替代者

2. **政策力度评估**
   - 国务院常务会议决定 > 部委联合发文 > 单部委意见 > 地方政策试点
   - "加快"、"大力推进"、"战略性" → 高力度信号
   - "研究"、"探索"、"适时" → 前期信号，力度较弱

3. **政策周期定位**
   - 吹风期：消息面活跃但政策未落地，预期交易为主
   - 落地期：正式文件出台，利好兑现需注意"买预期卖事实"
   - 执行期：配套细则和资金到位，业绩真正受益阶段

### 第四步：情绪面分析（第二权重）

**情绪评分体系（-5 到 +5）：**

| 分值 | 含义 | 典型信号 |
|------|------|----------|
| +5 | 极度利好 | 重大政策突破、行业被提升为国家战略 |
| +3~+4 | 明确利好 | 财政补贴、税收优惠、行业扶持文件 |
| +1~+2 | 温和利好 | 正面提及、调研考察、试点推广 |
| 0 | 中性 | 例行报道、数据发布无明显方向 |
| -1~-2 | 温和利空 | 监管关注、行业规范收紧 |
| -3~-4 | 明确利空 | 处罚通报、行业限制、加税 |
| -5 | 极度利空 | 行业被全面限制、重大安全事故 |

**多条新闻叠加时的情绪合成规则：**
- 同方向叠加：情绪强化，但注意饱和效应（不是简单相加）
- 反方向对冲：取主导方向，标注分歧
- 不同行业的新闻独立评分，不混合

### 第五步：产业链联动分析（第三权重）

**分析方法：**

1. 确定新闻直接影响的**核心行业**
2. 沿产业链向上游和下游延伸：
   - 上游：原材料、设备、技术供应商
   - 中游：制造、加工、集成环节
   - 下游：应用、消费、服务终端
3. 评估传导强度：直接受益 > 间接受益 > 边际受益

**常见产业链映射**（参考 `references/industry_chains.md` 获取完整映射表）：

示例：新能源汽车政策利好
- 核心：整车（比亚迪、长城、蔚来）
- 上游：锂矿（天齐锂业）、正极材料、电解液
- 中游：电池（宁德时代）、电机电控
- 下游：充电桩（特锐德）、换电站、车联网
- 关联：智能驾驶、汽车芯片、轻量化材料

### 第六步：资金面验证（第四权重）

用获取到的行情数据验证分析逻辑：
- 板块资金净流入是否与新闻方向一致？
- 龙头股成交量是否放大？
- 是否有涨停板效应（板块内多只个股涨停）？

资金面数据的作用是**验证和修正**前面的判断，而不是独立的分析依据。如果新闻明确利好但资金未响应，可能说明：
- 市场已经提前消化预期
- 整体市场环境不佳压制了板块表现
- 新闻利好程度不如预期

### 第七步：生成投资建议

#### 投资时间维度

用户可以选择关注的时间维度，默认全部覆盖：

**短线（1-5天）：** 适合热点轮动、事件驱动
- 关注：涨停板数量、板块热度排名、游资动向
- 风险特征：高波动、快进快出

**中线（1-3个月）：** 适合政策主题、行业趋势
- 关注：政策落地节奏、行业景气度变化、机构调研频率
- 风险特征：中等波动、需跟踪政策执行

**长线（半年以上）：** 适合产业升级、价值投资
- 关注：行业空间、公司竞争力、估值水平
- 风险特征：低波动但需承受短期回撤

#### 标的筛选输出

对每个推荐标的，输出以下信息：

```
股票/ETF名称 | 代码 | 所属板块
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
推荐逻辑：[1-2句话说明为什么这条新闻利好这只标的]
受益路径：新闻事件 → 行业影响 → 公司受益点
情绪评分：+X（利好/利空程度）
时间维度：短线 / 中线 / 长线
风险等级：低 / 中 / 高 / 极高
建议仓位：X%-Y%（占总仓位比例）
关键风险：[需要注意的主要风险点]
```

#### 风险评估与仓位建议

**风险等级判定：**
- 低风险：大盘蓝筹ETF、政策确定性强、估值合理
- 中风险：行业ETF、政策预期中、行业龙头个股
- 高风险：中小盘个股、政策仅在吹风期、概念炒作初期
- 极高风险：次新股、纯概念无业绩、逆政策方向

**仓位建议原则：**
- 单只个股建议仓位不超过总仓位的10%
- 单个板块/主题总仓位不超过30%
- 风险等级越高，建议仓位越低
- 提醒用户这是参考建议，实际投资需结合个人风险承受能力

### 第八步：输出格式

#### 对话输出

在对话中给出结构化但自然的分析，包含：
1. 新闻概述与情绪判断
2. 受影响行业与产业链分析
3. 推荐标的列表（按推荐度排序）
4. 整体风险提示

#### Excel 输出（当用户要求或新闻/标的较多时）

生成 xlsx 文件，参考 xlsx skill（路径 `/mnt/skills/public/xlsx/SKILL.md`）的规范来创建。

**工作表结构：**

Sheet 1 - 新闻分析汇总：
| 序号 | 新闻标题 | 来源 | 发布时间 | 情绪评分 | 影响行业 | 核心判断 |

Sheet 2 - 推荐标的：
| 股票/ETF | 代码 | 板块 | 推荐逻辑 | 情绪评分 | 时间维度 | 风险等级 | 建议仓位 | 关键风险 |

Sheet 3 - 板块资金流向（如有数据）：
| 板块名称 | 今日涨跌% | 资金净流入(亿) | 5日资金流向 | 相关新闻 |

**格式要求：**
- 利好用绿色背景，利空用红色背景（与A股涨跌颜色一致：红涨绿跌）
- 注意：A股的颜色惯例与欧美相反！红色=上涨=利好，绿色=下跌=利空
- 风险等级用条件格式：低=绿，中=黄，高=橙，极高=红
- 建议仓位用数据条可视化
- 表头冻结，添加筛选器

## 定时自动抓取与分析（进阶功能）

这是这个 skill 最有价值的进阶能力——把"每次手动问"变成"自动化持续监控"。

### 设计思路

Claude 本身没有后台常驻进程，所以"定时"需要外部触发器 + Claude 执行的组合：

```
外部定时器（cron / 云函数 / 手机闹钟）
    ↓ 到点触发
Claude（通过 API / CLI / 手动打开对话）
    ↓ 收到预设的 prompt
执行抓取 → 分析 → 生成报告
    ↓ 完成后
推送结果（邮件 / 微信 / 钉钉 / 本地保存）
```

### 四种部署方案

所有方案的核心都依赖 `scripts/fetch_news.py`，只是触发方式不同。

#### 方案 A：Claude Code + cron（全自动，推荐技术用户）

适合有服务器或长期运行的开发环境。

```bash
# 1. 生成定时配置
python scripts/fetch_news.py --mode schedule --topics "人工智能,新能源,半导体" --frequency daily

# 2. 查看配置中的 cron 表达式，添加到 crontab
crontab -e
# 添加类似这样的行：
# 0 9 * * 1-5  claude -p "$(cat ~/prompts/盘前扫描.txt)" > ~/reports/$(date +\%Y\%m\%d)_盘前.md 2>&1
# 35 11 * * 1-5 claude -p "$(cat ~/prompts/午间快报.txt)" > ~/reports/$(date +\%Y\%m\%d)_午间.md 2>&1
# 30 15 * * 1-5 claude -p "$(cat ~/prompts/盘后复盘.txt)" > ~/reports/$(date +\%Y\%m\%d)_盘后.md 2>&1
```

#### 方案 B：Anthropic API + Python 脚本（全自动，最灵活）

适合想要完全自定义的用户。可部署到任何支持 Python 的地方。

```bash
# 1. 生成部署脚本
python scripts/fetch_news.py --mode api_script --topics "AI,光伏" --output ~/scheduled_analysis.py

# 2. 配置 API Key
export ANTHROPIC_API_KEY="sk-ant-..."

# 3. 用 cron 或云函数定时执行
# cron 方式：
crontab -e
# 0 9 * * 1-5 python3 ~/scheduled_analysis.py

# 云函数方式（阿里云函数计算、AWS Lambda 等）：
# 上传脚本 → 创建定时触发器 → 配置环境变量
```

生成的脚本内置了：
- 自动判断时段（盘前/午间/盘后/周末）
- 结果保存到本地 Markdown 文件
- 可选邮件通知（QQ邮箱/Gmail/企业邮箱）
- 可选企业微信/钉钉 webhook 推送

#### 方案 C：Claude.ai 手动触发（最简单，无需技术）

适合不想折腾部署的普通用户。

```bash
# 1. 生成各时段的提示词
python scripts/fetch_news.py --mode prompt --topics "人工智能,消费" --style 全部

# 2. 把生成的提示词保存到手机备忘录
# 3. 设置手机闹钟：9:00 / 11:35 / 15:30
# 4. 闹钟响时打开 Claude.ai → 新对话 → 粘贴提示词 → 等待结果
```

用户也可以直接在对话中说"帮我生成盘前扫描的提示词，关注AI和新能源"，Claude 会运行脚本并输出现成的提示词。

#### 方案 D：iOS 快捷指令 / Android Tasker（半自动）

适合手机重度用户。

iOS 快捷指令设置：
1. 新建「自动化」→ 时间触发（每天 9:00）
2. 动作 → 打开 App → Claude
3. （进阶）如果配置了 API：动作 → 获取 URL 内容 → 调用 Anthropic API → 结果写入备忘录

Android Tasker：
1. 新建 Profile → 时间触发
2. Task → 打开 Chrome → 导航到 claude.ai
3. （进阶）Task → HTTP Request → 调用 API → 通知显示结果

### 交易时段感知

`scripts/fetch_news.py` 生成的提示词会根据时段自动调整关注重点：

| 时段 | 时间 | 自动关注重点 |
|------|------|------------|
| 盘前扫描 | 9:00 | 隔夜政策、央行公告、外盘影响、期指走势 |
| 午间快报 | 11:35 | 上午异动板块、涨停催化剂、突发消息 |
| 盘后复盘 | 15:30 | 全日涨跌原因、资金流向、次日主线判断 |
| 周末研判 | 周六 10:00 | 本周政策梳理、板块轮动、下周事件预告 |

### 多主题监控

可以同时监控多个互不相关的主题，脚本会为每个主题独立生成搜索计划：

```bash
# 同时监控多个赛道
python scripts/fetch_news.py --mode workflow --topics "人工智能,新能源车,半导体,低空经济" --scope full

# quick 模式只搜 P1+P2 源，速度更快，适合午间快报
python scripts/fetch_news.py --mode workflow --topics "AI,光伏" --scope quick
```

### 当 Claude 在对话中接收到定时触发请求

当用户在对话中说类似"帮我设置每天自动分析"、"我想定时监控XX板块"这样的话时：

1. 先问用户关注哪些主题、偏好哪种投资风格
2. 运行 `python scripts/fetch_news.py --mode schedule --topics "..." --frequency daily`
3. 向用户展示四种部署方案，让用户选择适合自己的
4. 如果用户选择 API 脚本方案，再运行 `--mode api_script` 生成可部署的脚本文件
5. 如果用户选择手动方案，生成各时段的提示词供用户保存

## 重要提醒

**免责声明（每次输出必须包含）：**

> ⚠️ 免责声明：以上分析仅供参考，不构成投资建议。股市有风险，投资需谨慎。Claude 的分析基于公开信息和逻辑推理，无法预测市场实际走势。请结合自身风险承受能力和投资经验做出独立判断。

这不是走过场——Claude 确实无法预测市场，这个提醒是对用户真正负责任的态度。

**分析质量原则：**
- 宁可少推荐，不要乱推荐。如果新闻影响不明确，说"影响不确定"比硬给结论好
- 永远标注信息的时效性和来源可靠度
- 如果获取不到实时行情数据，明确告知用户数据局限性
- 避免后验偏见：不要因为股票已经涨了就说"果然利好"
